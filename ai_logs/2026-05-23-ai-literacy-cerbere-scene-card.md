## Change

Added a dedicated Cerbere scene card for the Hercule AI literacy assets.

The card reframes Cerbere around the governance of return rather than generic memory storage:

- the Pommes mature a deliverable under responsibility;
- Cerbere governs what remains after the deliverable;
- the core issue is not accumulation but deciding what has the right to return;
- traces must be classified by status: ephemeral, draft, hypothesis, candidate, verified, validated, sensitive, archive, memory candidate, canonical memory;
- punctual use does not create a right of dwelling;
- a poorly guarded memory can make dead material return as if it were valid.

Key retained formulas:

```text
Garder les seuils du retour.
Garder n'est pas accumuler. C'est decider ce qui a le droit de revenir.
Tout ne doit pas passer. Tout ne doit pas rester.
L'usage ponctuel n'est pas un droit de demeure.
Une memoire mal gardee fait revenir ce qui aurait du rester mort.
Le valide peut rester. Le candidat doit rester marque. Le sensible doit rester garde. L'obsolete doit pouvoir mourir.
```
