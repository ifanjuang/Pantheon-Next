# Pantheon RPG visual system

Date: 2026-05-14

## Change

Added `docs/assets/pantheon-rpg/README.md`.

The new document defines a conceptual visual system for representing Pantheon Next as a governed decision RPG.

It includes:

- visual intent;
- doctrine-preserving metaphor rules;
- poster strata;
- source / knowledge / memory / deliverable distinctions;
- companion gods as non-runtime helpers;
- player agency rules;
- traps, loots, quests and side quests;
- roadmap for developing the poster and later image assets;
- planned asset folder structure;
- root README integration deferred until visual validation.

## Reason

The project needs a dedicated place to develop the Pantheon RPG poster concept progressively without overloading the root README or claiming implementation status.

This keeps the visual communication effort separate from canonical governance doctrine while preserving traceability.

## Governance boundary

This change is documentation only.

It does not introduce:

- execution runtime;
- agent runtime;
- tool runtime;
- scheduler;
- provider routing;
- workflow engine;
- memory auto-promotion;
- asset generation pipeline.

The new README explicitly marks the RPG system as a conceptual visual asset, not implemented governance doctrine.

## Risks and limitations

- The visual metaphor may be misread as autonomous runtime behavior if future images overemphasize gods, workshops or oracles.
- A single poster may become overloaded if all sections are displayed at equal weight.
- Root README integration remains intentionally deferred until visual validation.
- No generated image asset has been added yet.
