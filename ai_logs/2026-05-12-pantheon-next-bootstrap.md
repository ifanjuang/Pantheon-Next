# Pantheon Next Bootstrap

Date: 2026-05-12

## Summary

Initial clean governance-first extraction from Pantheon-OS.

The objective of this bootstrap is to create a coherent canonical repository focused on:

- governance;
- schemas;
- validation;
- doctrine;
- approvals;
- evidence discipline;
- runtime boundaries.

## Explicit exclusions

The following categories are intentionally excluded from the bootstrap:

- execution runtime;
- agent scheduler;
- queue systems;
- provider routing runtime;
- autonomous orchestration;
- auto-promoted memory;
- hidden workflow engines;
- automatic Hermes profile installation;
- Docker runtime stack.

## Governance doctrine

OpenWebUI exposes.
Hermes Agent executes.
Pantheon Next governs.

## Migration strategy

Pantheon-OS remains the historical and legacy source repository.
Pantheon-Next becomes the canonical governance-first repository.

Migration is selective.

Only governance-relevant assets are migrated by default:

- governance Markdown;
- schemas;
- validation tools;
- AI logs;
- governance-oriented tests;
- context-pack specifications.

## Status

Bootstrap started.

Repository currently under controlled migration.
