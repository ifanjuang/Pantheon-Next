## Purpose

The new files document how to correct, prompt and sequence future Pantheon RPG visual boards without changing the core Pantheon doctrine.

The guidance answers the production question:

```text
Which boards should be decomposed, simplified, enriched or professionalized?
```

## Decisions recorded

- Decompose boards that explain a flow, boundary, passage, intake, validation or memory transition.
- Simplify boards that explain a concept, role family or mental model.
- Enrich details only when they carry governance meaning.
- Add a shared legend before producing too many new boards.
- Decompose the citadel and port because they carry the main professional workflows.
- Simplify the world map and Olympus because they carry conceptual explanations.
- Professionalize the player board so the user reads as a responsible professional, not a fantasy warrior.
