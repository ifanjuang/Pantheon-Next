# AI log — Single renderer for Hermes live and public demo

Date: 2026-07-16

## Scope

Removed the separate GitHub Pages renderer and made the public demonstration run
the exact native Hermes dashboard-plugin JavaScript and CSS bundle.

The public page supplies a synthetic, read-only Hermes SDK harness. Native read
methods return the fixture; all mutation methods reject, SDK action buttons are
disabled, and `window.confirm` is fail-closed.

## Canonical renderer

The installable plugin bundle remains canonical:

```text
templates/hermes/dashboard-plugins/pantheon-modules/dashboard/dist/
  index.js
  style.css
```

The public copies are generated by
`.github/scripts/sync_hermes_dashboard_preview.py`. Tests require byte-for-byte
equality, preventing the GitHub preview from drifting away from Hermes.

## Fixture coverage

The synthetic fixture now covers Mem0, the Pantheon policy MCP, n8n, a
direct-config MCP example, plugin inventory, LangGraph and Memvid candidate
placements generated by the native bundle, and all six bounded night operations.
Every demo Cron job is paused and disabled.

## Boundary

This is still a public demonstration, not an Hermes connection. The permanent
banner identifies synthetic data. No secret is accepted or persisted and no
install, enable, disable, probe, trigger, schedule or removal operation can run.
