## Why

Understand-Anything remains useful as a repository radiography tool.

The danger is that a clear generated graph can be mistaken for validated architecture, proof, memory or approval.

This intervention preserves the useful pattern while recording the authority drift as a stable rejected pattern and persistent tension.

## Boundary and limitations

This intervention is documentation-only.

It does not:

- run Understand-Anything;
- install a Hermes skill;
- create a graph runtime;
- create a GraphRAG runtime;
- validate repository architecture;
- approve generated graph output;
- promote graph output to memory;
- create tests, operations tooling, runtime checks or automatic enforcement.

## Central rule

```text
A graph may reveal structure.
It does not validate structure.
It does not approve architecture.
It does not create memory.
```
