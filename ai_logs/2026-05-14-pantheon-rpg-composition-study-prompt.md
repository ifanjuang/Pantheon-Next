## Reason

The full master poster prompt is intentionally dense.

A reduced composition prompt is needed before generating the final poster to test:

- spatial hierarchy;
- four-strata readability;
- Greek antique city identity;
- source / knowledge / memory / craft separation;
- human validation logic;
- doctrine-safe RPG metaphor.

## Governance boundary

This is documentation-only prompt work.

It does not introduce:

- generated image assets;
- image generation automation;
- execution runtime;
- workflow runtime;
- tool runtime;
- scheduler;
- provider routing;
- automatic memory promotion;
- root README integration.

The prompt remains a design artifact, not governance doctrine.

## Risks and limitations

- The composition prompt still may be too rich for some image models.
- Generated typography should not be trusted and should be replaced later by manual overlay.
- The image must be rejected if boats enter the city, knowledge becomes memory directly, gods dominate the player or the underground layer looks like backend infrastructure.
