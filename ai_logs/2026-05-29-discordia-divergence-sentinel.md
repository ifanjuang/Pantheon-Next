# 2026-05-29 - Discordia divergence sentinel

## Summary

Added `docs/governance/DISCORDIA.md` as support doctrine for a material divergence sentinel.

Discordia is introduced as a governance function that detects, preserves and qualifies material divergence.

Discordia is not introduced as a final judge, runtime agent, hidden debate system or new ZEUS.

## Files changed

- `docs/governance/DISCORDIA.md`

## Doctrine

Discordia protects useful disagreement from premature smoothing.

Core rule:

```text
Discordia detects divergence.
Discordia preserves material tension.
Discordia qualifies disagreement.
ZEUS decides status and procedure.
Agora exposes deliberation.
The human decides when the conflict exceeds procedure.
```

## Relationship to roles

Discordia does not replace existing Pantheon responsibilities.

```text
ATHENA detects structural incoherence.
ARGOS detects source and evidence weakness.
THEMIS detects risk, contradiction and approval boundary.
APOLLO detects clarity and formulation ambiguity.
DISCORDIA detects that their tensions must not be smoothed away.
ZEUS decides status and next procedure.
The human decides when required.
```

## Boundary

This pass is documentation-only.

It does not implement:

- Discordia runtime;
- hidden debate runtime;
- contradiction engine;
- multi-agent conversation;
- approval engine;
- memory arbiter;
- source validator;
- workflow orchestrator;
- automatic User Decision Gate trigger;
