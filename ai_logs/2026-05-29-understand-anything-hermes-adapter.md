## Why

Understand-Anything is useful as a repository and documentation radiography tool.

It may help a Hermes-side worker prepare structural reports, impact notes, onboarding guides or Evidence Pack Candidates.

The same output can become risky if treated as truth, memory, approval or governance doctrine.

The documentation therefore keeps the useful pattern while preserving Pantheon boundaries.

## Boundary and limitations

This intervention is documentation-only.

It does not:

- install external software;
- install Hermes skills;
- adopt Hermes Desktop;
- create a runtime integration;
- create an OpenWebUI extension;
- create a graph runtime;
- create repository automation;
- create automatic Evidence Pack writing;
- create automatic memory promotion;
- modify schemas, tests, operations, Docker, environment files, `pyproject.toml` or other protected runtime areas.

## Risk notes

- A structural graph may look more authoritative than it is.
- Static extraction and semantic interpretation must remain separated.
- Business-domain mapping remains hypothetical unless supported by evidence and approval.
- A generated graph may support an Evidence Pack Candidate, but it is not evidence, doctrine or memory by itself.
- Future operational use requires separate review against current upstream documentation and local security posture.
