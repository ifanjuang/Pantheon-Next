# Architecture use-case path landing follow-up

Date: 2026-06-16
Branch: `docs-usecase-path`

## What changed

Adds a landing-page follow-up focused on visible architecture use cases and a concrete user path.

The rewrite adds:

- a simple six-step user journey: choose matter, deposit piece, ask question, receive note, see alerts, decide;
- three architecture use cases: VISA validation request, PLU / mairie response, client programme change;
- a mock Pantheon note showing question, reading, expected sources, risk/status pills and decision expected;
- stronger emphasis on time returned to conception, drawing, product research, norms and regulations.

## Why

After the architecture-first landing rewrite, the next missing proof was visible usage. The page needed to show, quickly, how an architect would use the system tomorrow without feeling that Pantheon is a complex governance machine.

## Doctrine alignment
