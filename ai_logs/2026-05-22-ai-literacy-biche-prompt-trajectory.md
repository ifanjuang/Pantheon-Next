## Change

Added a note to the Biche de Cerynie scene card on initial prompt trajectory versus correction loops.

The update clarifies that:

- a good initial prompt does not guarantee a perfect output;
- but the first prompt sets a trajectory;
- later corrections can improve the surface while failing to repair a wrong initial direction;
- complex work still needs iteration;
- the first iteration should often clarify the frame before production.

Key retained formulas:

```text
Corriger une mauvaise demande ameliore la surface.
Cadrer juste des le depart ameliore la trajectoire.

L'IA corrige bien une forme.
Elle repare moins bien une direction mal donnee.
```

This reinforces the Biche angle: approaching a fragile intention is not only about post-hoc edits, but about knowing the system and giving it a sufficiently fair first direction.
