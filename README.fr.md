# Pantheon Next

> English version: [README.md](README.md)

> Sources. Preuves. Mémoire. Validation.  
> Un cadre pour garder la maîtrise des dossiers sensibles.

Les professionnels ne manquent pas d’informations.

Ils manquent de certitude sur ce qui peut être utilisé, transmis, conservé, contesté ou décidé.

Un dossier peut contenir des contrats, des plans, des rapports, des emails, des devis, des règlements, des notes, des PDFs, des sources web, des images, des transcriptions de réunion et des versions contradictoires. L’IA peut accélérer la lecture et la transformation de ces éléments. Elle peut aussi mélanger les contextes, lisser les contradictions ou transformer une hypothèse en vérité apparente.

Pantheon Next sert à garder la maîtrise.

Il cadre les demandes, rend les sources visibles, structure les preuves, isole les dossiers, contrôle la mémoire et maintient la validation humaine au centre.

```text
L’information entre.
Pantheon la cadre.
Hermes exécute.
OpenWebUI expose.
L’humain décide.
Seul le validé demeure.
```

Pantheon n’est pas une IA de plus.

C’est la méthode qui permet d’utiliser l’IA sans lui abandonner le dossier.

## Pourquoi ça compte même si vous n’utilisez pas l’IA

Pantheon Next ne s’adresse pas seulement aux professionnels qui utilisent déjà l’IA.

L’IA devient progressivement une manière de produire, résumer, transmettre, comparer, corriger, contester et réutiliser l’information. Même si vous ne l’utilisez pas directement, une partie des informations qui arrivent dans vos dossiers peut déjà avoir été rédigée, reformulée, synthétisée ou influencée par l’IA.

La question n’est donc plus seulement :

```text
Qu’est-ce que l’IA peut faire ?
```

La question devient :

```text
Qu’est-ce que l’IA a déjà transformé ?
Qu’est-ce qui peut entrer dans un dossier ?
Qu’est-ce qui doit rester humain ?
Qu’est-ce qui exige une preuve ?
Qu’est-ce qui peut devenir mémoire ?
Qu’est-ce qui doit être refusé ?
```

Pantheon donne aux professionnels une méthode pour aborder l’IA progressivement : comprendre d’abord, tester ensuite, cadrer les usages, puis déléguer certaines tâches seulement lorsque les règles sont claires.

Vous pouvez commencer sans automatiser.

Vous pouvez commencer par comprendre.

## Pas une app de plus à surveiller

Pantheon Next n’a pas vocation à devenir une nouvelle interface à consulter toute la journée.

Les professionnels ont déjà leurs outils, leurs dossiers, leurs emails, leurs réunions, leurs échéances et leurs méthodes. Leur problème n’est pas de manquer d’applications. Leur problème est de garder la maîtrise quand l’IA, les sources externes, les documents et la mémoire commencent à se mélanger.

Pantheon intervient lorsque le travail devient sensible :

- quand une source doit être vérifiée ;
- quand une sortie IA doit être relue ;
- quand un dossier ne doit pas contaminer un autre dossier ;
- quand une hypothèse ne doit pas devenir une vérité ;
- quand la mémoire ne doit pas se promouvoir seule ;
- quand une décision doit laisser une trace.

Pantheon n’est pas fait pour capter l’attention.

Il est fait pour préserver la maîtrise.

## L’IA brute fragilise. L’IA maîtrisée améliore.

Pantheon Next ne part pas d’une confiance naïve dans l’IA.

Mal cadrée, l’IA peut produire des erreurs convaincantes, affaiblir la vigilance, lisser les productions, déplacer la responsabilité, contaminer la mémoire, exposer des informations sensibles ou rendre l’utilisateur dépendant d’un flux qu’il ne maîtrise plus.

Mais ces risques ne condamnent pas l’IA.

Ils montrent pourquoi elle doit être cadrée.

Bien maîtrisée, l’IA peut au contraire renforcer le travail professionnel :

- repérer ce qu’on aurait manqué ;
- révéler des contradictions entre documents ;
- comparer plusieurs versions plus vite ;
- reformuler des hypothèses pour les rendre discutables ;
- extraire obligations, risques et points faibles ;
- structurer une décision ;
- réduire le temps passé sur les tâches répétitives ;
- rendre certaines vérifications plus systématiques ;
- tester plusieurs angles avant de trancher ;
- documenter ce qui doit être relu, validé ou rejeté.

La différence ne vient pas seulement du modèle.

Elle vient du cadre.

Une IA non maîtrisée produit des réponses.

Une IA maîtrisée produit des propositions relisibles, sourcées, limitées, discutables et validables.

## Ce que Pantheon apporte concrètement

Pantheon Next permet de produire :

- une tâche cadrée plutôt qu’un prompt vague ;
- une synthèse sourcée plutôt qu’une réponse isolée ;
- un Evidence Pack plutôt qu’une confiance aveugle ;
- des Memory Candidates plutôt qu’une mémoire automatique ;

- un workflow professionnel plutôt qu’un usage IA dispersé.

Le but n’est pas de produire plus.

Le but est de produire mieux : avec sources, limites, preuves, responsabilités et décisions visibles.

## Objets clés

Pantheon traduit la maîtrise professionnelle en objets de gouvernance concrets.

| Objet | Rôle |
|---|---|
| Task Contract | Cadre la demande, le périmètre, les sources, les limites, la sortie attendue et le niveau de validation. |
| Evidence Pack | Conserve les sources, hypothèses, risques, contradictions, outils, actions et décisions. |
| Niveaux d’approbation | Définissent ce qui peut être rédigé, exécuté, transmis, mémorisé ou canonisé. |
| Memory Candidate | Information proposée à la conservation, jamais canonique par défaut. |
| Canonical Memory | Mémoire validée, bornée et reliée aux preuves. |
| External Tools Policy | Contrôle ce qui peut entrer, sortir, être filtré, anonymisé ou rejeté. |
| Context Pack | Fournit aux couches d’exécution externes le contexte gouverné minimal nécessaire. |
| AI Log | Garde la trace des interventions significatives assistées par IA. |

Pantheon ne remplace pas le jugement professionnel.

Il structure les conditions dans lesquelles une sortie IA peut devenir un travail professionnel.

## Doctrine opératoire

```text
OpenWebUI expose.
Hermes Agent exécute.
Pantheon Next gouverne.
```

OpenWebUI est le cockpit : chat, fichiers, Knowledge Bases, résultats, demandes de validation et affichage des Evidence Packs.

Hermes Agent est le runtime d’exécution externe : OCR, transcription, recherche, comparaison, extraction, skills, tools, workers et workflows opérationnels.

Pantheon Next est la couche de gouvernance : doctrine, rôles, Task Contracts, approvals, Evidence Packs, politique mémoire, context packs et politique des outils externes.

Cette frontière est centrale.

Pantheon Next gouverne l’exécution.

Il ne l’exécute pas.

## Sécurité et mémoire

Déposer une information professionnelle sensible dans un système IA non contrôlé n’est pas un geste anodin.

Pantheon Next est conçu autour de :

- cloisonnement des dossiers ;
- préférence locale lorsque possible ;
- mémoire contrôlée ;
- anonymisation ;
- filtrage des sorties externes ;
- connecteurs gouvernés ;
- traces de preuve ;
- approbation humaine ;
- règles de promotion mémoire ;
- Canonical Memory bornée.

Une réponse générée n’est pas automatiquement une vérité.

Une source retrouvée n’est pas automatiquement une preuve.

Une Memory Candidate n’est pas une Canonical Memory.

La mémoire reste bornée, relisible, reliée aux preuves et gouvernable.
