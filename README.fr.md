# Pantheon Next

> English version: [README.md](README.md)

> Couche de gouvernance pour le travail professionnel assisté par IA.

Pantheon Next transforme les sorties IA en livrables traçables, reliés aux preuves et soumis à validation.

Il aide les professionnels à utiliser l’IA sur des dossiers sensibles sans perdre la confidentialité, le contrôle des sources, le cloisonnement projet, la mémoire gouvernée ni l’autorité humaine.

```text
L’IA ouvre les possibles.
Pantheon cadre le travail.
Hermes exécute.
OpenWebUI expose.
L’humain décide.
Seul le validé demeure.
```

Une bonne réponse IA ne suffit pas.

Une réponse professionnelle doit être traçable.

Vous déléguez l’exécution.

Vous ne déléguez jamais la décision.

---

## Le problème

La plupart des outils IA commencent par un prompt.

Le travail professionnel commence par un dossier.

Un contrat. Un plan. Un rapport. Un email client. Un devis. Une réglementation. Une note de réunion. Un PDF sensible. Une source web. Un ensemble de versions contradictoires.

L’IA peut accélérer ce travail.

Elle peut aussi le contaminer.

Elle mélange des signaux utiles avec des hypothèses, des informations périmées, des sources faibles, une fausse certitude et des fuites de contexte. Le danger n’est pas seulement que l’IA puisse se tromper. Le danger, c’est qu’elle puisse se tromper avec assurance, puis être réutilisée, stockée ou transférée dans le mauvais contexte professionnel.

Pantheon Next existe pour gouverner ce risque.

---

## Le produit

Pantheon Next n’est pas un chatbot de plus.

C’est une couche de gouvernance qui cadre la manière dont le travail IA est demandé, exécuté, relu, conservé ou rejeté.

Il s’appuie sur des objets de gouvernance concrets :

| Objet | Rôle |
|---|---|
| Task Contract | Cadre la demande, le périmètre, les sources, les limites, la sortie attendue et le niveau de validation. |
| Evidence Pack | Conserve les sources, hypothèses, risques, contradictions, outils, actions et décisions. |
| Niveaux d’approbation | Définissent ce qui peut être rédigé, exécuté, transmis, mémorisé ou canonisé. |
| Mémoire candidate | Information proposée à la conservation, jamais canonique par défaut. |
| Mémoire canonique | Mémoire validée, bornée et reliée aux preuves. |
| External Tools Policy | Contrôle ce qui peut entrer, sortir, être filtré, anonymisé ou rejeté. |
| Context Pack | Fournit aux couches d’exécution le contexte gouverné minimal nécessaire. |
| AI Log | Garde la trace des interventions significatives assistées par IA. |

Pantheon ne remplace pas le jugement professionnel.

Il structure les conditions dans lesquelles une sortie IA peut devenir un travail professionnel.

## Doctrine opératoire

```text
OpenWebUI expose.
Hermes Agent exécute.
Pantheon Next gouverne.
```

OpenWebUI est le cockpit utilisateur : chat, fichiers, Knowledge Bases, résultats, demandes de validation et affichage des Evidence Packs.

Hermes Agent est le runtime d’exécution externe : OCR, transcription, recherche, comparaison, extraction, skills, tools, workers et workflows opérationnels.

Pantheon Next est la couche de gouvernance : doctrine, rôles, Task Contracts, approvals, Evidence Packs, politique mémoire, context packs et politique des outils externes.

Cette frontière est centrale.

Pantheon Next gouverne l’exécution.

Il ne l’exécute pas.

## Ce que Pantheon Next n’est pas

Pantheon Next n’est pas :

- un chatbot ;
- un agent runtime autonome ;
- un tool runtime ;
- un routeur de providers LLM ;
- un scheduler ;
- un moteur de workflow caché ;
- un plugin manager libre ;
- un système de mémoire auto-promue ;
- un remplacement du jugement professionnel.

Pantheon définit les règles du travail professionnel assisté par IA.

Il ne devient pas le runtime.

## Comment ça s’utilise concrètement

Vous ne commencez pas par configurer des agents.

Vous partez d’une situation professionnelle.

1. **Apporter une intention**  
   Une question, un dossier, un document, une décision ou un livrable à préparer.

2. **Ajouter des sources**  
   PDFs, emails, plans, notes, liens web, transcriptions, images ou fichiers projet.

3. **Poser les contraintes**  
   Confidentialité, périmètre projet, accès externes, sortie attendue et niveau de validation.

4. **Cadrer la tâche**  
   Pantheon crée ou applique un Task Contract.

5. **Exécuter sous contrat**  
   Hermes ou un autre runtime externe effectue extraction, OCR, transcription, comparaison, recherche ou synthèse.

6. **Relire l’Evidence Pack**  
   Sources, hypothèses, contradictions, risques et points faibles restent visibles.

7. **Décider ce qui demeure**  
   L’humain valide, rejette, corrige, transmet ou promeut des mémoires candidates.

## Les outils du quotidien comme points d’entrée gouvernés

Pantheon ne remplace pas les outils du quotidien.

Il gouverne ce qu’ils peuvent apporter au dossier professionnel.

| Canal | Rôle | Statut |
|---|---|---|
| OpenWebUI | Cockpit utilisateur principal | Cockpit visé |
| Hermes Agent | Runtime d’exécution externe | Runtime visé |
| Fichiers locaux / PDFs | Matière documentaire du dossier | Entrée visée |
| OCR / transcription | Traitement des documents et de la voix | Capacité d’exécution visée |
| Gmail | Emails et pièces jointes | Point d’entrée gouverné visé |
| Google Drive / Docs / Sheets | Documents et sources tabulaires | Point d’entrée gouverné visé |
| Google Calendar / Keep | Échéances, notes et rappels | Point d’entrée gouverné visé |
| Notion / Trello | Tâches, connaissance projet et tableaux | Point d’entrée gouverné visé |
| WhatsApp / Telegram | Messages, notes vocales et images | Futur point d’entrée gouverné |
| Recherche web | Découverte de sources externes | Flux externe gouverné |

Ces éléments sont des points d’entrée gouvernés visés, pas des connecteurs runtime Pantheon intégrés automatiquement, sauf implémentation séparée dans la couche d’exécution externe.

Ces outils restent des canaux.

Ils ne deviennent pas mémoire canonique.

Toute source ne devient pas vérité.

## Sécurité et mémoire

Déposer une information professionnelle sensible dans un système IA non contrôlé n’est pas un geste anodin.

Pantheon Next est conçu autour de :

- cloisonnement des dossiers ;
- préférence locale lorsque possible ;
- mémoire contrôlée ;
- anonymisation ;
- filtrage des sorties externes ;
- connecteurs gouvernés ;
- traces de preuve ;
- approbation humaine ;
- règles de promotion mémoire ;
- mémoire canonique bornée.

Une réponse générée n’est pas automatiquement une vérité.

Une source retrouvée n’est pas automatiquement une preuve.

Une mémoire candidate n’est pas une mémoire canonique.

La mémoire reste bornée, relisible, reliée aux preuves et gouvernable.
