# Pantheon Next

> Version française : [README.fr.md](README.fr.md)

> Sources. Evidence. Memory. Validation.  
> A control frame for sensitive professional dossiers.

Professionals do not lack information.

They lack certainty about what can be used, shared, kept, challenged or decided.

A dossier may contain contracts, plans, reports, emails, quotes, regulations, notes, PDFs, web sources, images, meeting transcripts and conflicting versions. AI can accelerate how these materials are read and transformed. It can also blur contexts, flatten contradictions or turn an assumption into apparent truth.

Pantheon Next exists to keep control.

It frames requests, makes sources visible, structures evidence, isolates dossiers, controls memory and keeps human validation at the center.

```text
Information enters.
Pantheon frames it.
Hermes executes.
OpenWebUI exposes.
The human decides.
Only the validated remains.
```

Pantheon is not another AI tool.

It is the method that lets professionals use AI without handing over the dossier.

## Raw AI weakens. Controlled AI improves.

Pantheon Next does not start from naive trust in AI.

Uncontrolled AI can produce convincing errors, weaken vigilance, flatten outputs, blur responsibility, contaminate memory, expose sensitive information or make users dependent on a flow they no longer control.

But these risks do not condemn AI.

They explain why it must be framed.

When properly controlled, AI can strengthen professional work:

- detect what may have been missed;
- reveal contradictions between documents;
- compare multiple versions faster;
- reformulate assumptions so they can be discussed;
- extract obligations, risks and weak points;
- structure decisions;
- reduce time spent on repetitive tasks;
- make certain checks more systematic;
- test several angles before deciding;
- document what must be reviewed, approved or rejected.

The difference does not come only from the model.

It comes from the frame.

Uncontrolled AI produces answers.

Controlled AI produces reviewable, sourced, limited, debatable and approvable proposals.

## Core objects

Pantheon translates professional control into concrete governance objects.

| Object | Role |
|---|---|
| Task Contract | Frames the request, scope, sources, limits, expected output and validation level. |
| Evidence Pack | Records sources, assumptions, risks, contradictions, tools, actions and decisions. |
| Approval Levels | Define what can be drafted, executed, transmitted, memorized or canonized. |
| Memory Candidate | Information proposed for retention, never canonical by default. |
| Canonical Memory | Validated, scoped and evidence-linked memory. |
| External Tools Policy | Controls what can enter, leave, be filtered, anonymized or rejected. |
| Context Pack | Gives external execution layers the minimum governed context they need. |
| AI Log | Keeps a trace of significant AI-assisted interventions. |

Pantheon does not replace professional judgment.

It structures the conditions under which AI output can become professional work.

## Operating doctrine

```text
OpenWebUI exposes.
Hermes Agent executes.
Pantheon Next governs.
```

OpenWebUI is the cockpit: chat, files, Knowledge Bases, results, validation requests and Evidence Pack display.

Hermes Agent is the external execution runtime: OCR, transcription, search, comparison, extraction, skills, tools, workers and operational workflows.

Pantheon Next is the governance layer: doctrine, roles, Task Contracts, approvals, Evidence Packs, memory policy, context packs and external tools policy.

This boundary is central.

Pantheon Next governs execution.

It does not execute.

## Security and memory

Uploading sensitive professional information into uncontrolled AI systems is not a trivial action.

Pantheon Next is designed around:

- dossier isolation;
- local-first preference where possible;
- controlled memory;
- anonymization;
- external output filtering;
- governed connectors;
- evidence trails;
- human approval;
- memory promotion rules;
- scoped Canonical Memory.

A generated answer is not automatically truth.

A retrieved source is not automatically evidence.

A Memory Candidate is not Canonical Memory.

Memory remains scoped, reviewable, evidence-linked and governable.
