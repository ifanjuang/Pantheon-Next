# Legacy

Pantheon-OS is the historical repository associated with the project evolution before Pantheon-Next.

Pantheon-Next is the governance-first repository.

## Migration policy

Pantheon-Next migrates primarily:

- governance Markdown;
- schemas;
- validation tooling;
- AI logs;
- governance tests.

Runtime-oriented components are not migrated by default.
