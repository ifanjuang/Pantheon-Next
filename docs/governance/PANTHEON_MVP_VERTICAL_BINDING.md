## Current evidence gates

### Gate 1 — Current schema alignment

Required evidence:

- current Task Contract fixtures validate against the current vendored or referenced Pantheon contract;
- decision values match the canonical closed vocabulary;
- Decision Record identity, timestamp, digest and supersession fields align;
- retention authorization remains separate from output approval.

Status: to verify at the pinned repository state.

### Gate 2 — Source path containment

Required evidence:

- absolute paths refused;
- `..` traversal refused;
- resolved path remains under the declared workspace root;
- symlink escape is refused or explicitly bounded;
- tests cover the containment behavior.

Status: implementation work is reported in repository history; current evidence not yet accepted by Pantheon.

### Gate 3 — Role and stand-in clarity

Required evidence:

- deterministic runner is clearly identified as a Hermes-side stand-in or bounded external runner;
- terminal decision UI is clearly identified as an exposure stand-in;
- no local component claims Pantheon authority;
- no component claims authenticated human identity without an authenticated principal.

Status: boundary language is present in the README; executable entry points remain to inspect.

### Gate 4 — Decision and retention seam

Required evidence:

- system/runtime actors cannot approve;
- `approve` does not authorize external send;
- `approve` does not authorize durable retention;
- Register Candidate creation requires explicit retention authorization;
- decision and candidate digests are checked;
- supersession and refusal remain traceable.

Status: recent implementation work is visible; conformance review remains open.

### Gate 5 — CI and reproducibility

Required evidence:

- workflow run or equivalent immutable CI evidence for a pinned commit;
- always-on unit tests not silently skipped;
- pgvector-required tests fail loudly when configured infrastructure is unavailable;
- documented local reproduction procedure;
- test scope and exclusions visible.

Status: CI evidence not established for the current pinned merge commit through the available query.

### Gate 6 — Vendored upstream freshness

Required evidence:

- vendored Pantheon commit identified;
- differences against current Pantheon main reviewed;
- stale local schemas not presented as current authority;
- re-vendoring decision recorded when needed.

Status: to verify.

### Gate 7 — Human adoption decision

Even when Gates 1–6 are satisfied:

```text
verified external implementation != adopted binding
```

A scoped human decision must record environment, permitted use, data posture, activation conditions, rollback expectations and expiration/review date.

Status: no adoption decision recorded.
