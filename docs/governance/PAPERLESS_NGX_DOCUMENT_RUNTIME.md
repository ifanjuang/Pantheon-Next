# Paperless-ngx Document Runtime Candidate

Status: refused — no longer selected document-runtime path — refused.

Paperless-ngx is no longer a target architecture component or preferred binding for Pantheon Next.

The useful responsibilities previously explored through this candidate already have tool-agnostic owners:

```text
exact professional source identity / provenance
-> document lifecycle and source owners

bounded local/NAS source ingestion
-> co-located implementation candidate where currently implemented

structured extraction / OCR
-> separately selected extraction capability bindings

human Markdown workspace
-> OBSIDIAN_HINDSIGHT_WORKSPACE_MODEL.md

Knowledge publication
-> KNOWLEDGE_TAXONOMY.md and existing Knowledge owners

Evidence / approval / durable Register promotion
-> EVIDENCE_PACK.md, APPROVALS.md, MEMORY.md
```

Obsidian does not replace Paperless by becoming a DMS. Professional source files keep their own exact source/provenance identity; Obsidian remains a human-authored Markdown workspace and editable projection surface.

Paperless-specific tags, OCR, queues, API identifiers and document-management workflows must not become Pantheon business authority merely because historical implementation code exists.

```text
source file != Obsidian note
folder != governed Project identity
OCR text != source truth
runtime success != Evidence
optional binding absent != core ingestion unavailable
```

Historical Paperless implementation code, Compose overlays, catalog records, runbooks and `ai_logs/` remain provenance until consumers and protected-path consequences are independently verified and retired. Their presence does not restore Paperless as a selected dependency.
