Historical implementation code, templates and `ai_logs/` remain provenance until their consumers and protected-path consequences are independently verified and retired. Their presence does not restore OpenWebUI as an active dependency.

```text
historical code present != selected architecture
client connectivity != governance authority
UI display != approval
retrieval != Evidence
```
