# External Runtime Options

Status: stub — Non implémenté — à migrer depuis Pantheon-OS

This file is a placeholder to preserve governance references during Pantheon-Next bootstrap.

It is not canonical yet.

Do not use this file as implemented governance doctrine until migration and review are completed.

## Intended scope after migration

- governance evaluation of external runtimes considered for Hermes-side execution;
- review of candidate runtimes (orchestrators, workflow engines, agent frameworks) as inspiration or Hermes-side capability only;
- explicit reminder that no external runtime becomes a Pantheon-Next runtime;
- selection criteria: governance compatibility, candidate-only execution, approval respect, evidence support, no auto-promotion;
- forbidden integration patterns: central orchestrator inside Pantheon, hidden workflow engine, automatic skill installer, self-approval loops;
- audit and revocation rules for any external runtime previously approved on the Hermes side.

## Anti-runtime reminder

This document governs evaluation doctrine only.

It does not install, configure, deploy or operate any external runtime.

Pantheon Next must not embed an external runtime as its execution layer.
