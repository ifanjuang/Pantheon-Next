Le problème

Les agents IA deviennent vite opaques : trop de tools, trop de profils, trop de mémoire implicite, trop de workflows cachés. Le résultat peut être impressionnant, mais difficile à relire, à prouver, à valider ou à maintenir.

Risque

Runtime caché

Un cockpit ou un bridge peut glisser vers un moteur autonome si les frontières ne sont pas visibles.

Risque

Mémoire auto-promue

Une note utile peut devenir vérité persistante sans décision explicite.

Risque

Preuve floue

Une source retrouvée, une trace ou un graphe peut être confondu avec une preuve validée.

L’architecture cible

La règle n’est pas d’ajouter plus d’agents. La règle est de placer chaque capacité au bon niveau d’autorité.

Cockpit

OpenWebUI

Expose les documents, les statuts, les décisions et les résultats candidats. Il ne devient ni runtime, ni mémoire canonique, ni source de vérité.

Gouvernance

Pantheon Next

Qualifie les statuts : draft, candidate, Evidence Candidate, approved deliverable, Memory Candidate ou Canonical Memory.

Atelier

Hermes Agent

Exécute sous Task Contract. Il peut produire des candidats, des gaps et des risques. Il ne valide pas seul.

Carte interactive

La carte explique en langage simple ce qui est obligatoire, ce qui est optionnel, et pourquoi chaque outil reste à sa place.

Lecture

  • Trait plein : noyau obligatoire ou flux continu.
  • Trait pointillé : capacité optionnelle, activable plus tard sous contrat.
  • Clic sur une bulle : fichiers associés, rôle simple, règles à retenir.

Explorer la carte

Modules optionnels

Ces briques sont utiles, mais elles ne deviennent pas automatiquement Pantheon. Elles restent des capacités externes, bornées et gouvernées.

Préparation

Langflow

Flows déterministes : extraction, normalisation, préparation de Context Pack. Il prépare, il ne décide pas.

Workflow long

LangGraph

Checkpoint, pause, reprise, human-in-the-loop. Utile derrière Hermes ou un bridge, jamais comme cœur caché.

Observation

Langfuse

Traces et métadonnées d’exécution. Une trace aide l’audit, mais ne remplace jamais un Evidence Pack.

Relations

Provenance

Liens entre sources, claims, contradictions, outputs et mémoire. Un lien n’est pas une validation.

Exécution

Hermes skills

Compétences étroites, réutilisables, sous contrat. Un skill candidat n’est pas un skill installé.

Interface

OpenWebUI Actions

Boutons minces : demander une exécution, afficher un blocage, ouvrir un User Decision Gate.

Ce que Pantheon refuse

  • Pas de runtime agentique caché dans Pantheon.
  • Pas de mémoire auto-promue : une Memory Candidate n’est pas une Canonical Memory.
  • Pas d’approbation automatique : l’humain décide quand le statut l’exige.
  • Pas de confusion entre trace, source et preuve : Langfuse observe, GraphRAG relie, Evidence Pack prouve.
  • Pas de swarm par défaut : fiabilité ennuyeuse avant autorité élargie.

État réel du projet

Pantheon Next est actuellement une base de gouvernance documentaire, avec templates non exécutables et doctrines de placement. Les intégrations runtime ne sont pas présentées comme implémentées.

Important. Les templates OpenWebUI, Hermes, Langflow, Langfuse et provenance sont des candidats déclaratifs. Ils ne sont pas installés, déployés ou exécutés.
