Pantheon Next — qui fait quoi ?

Trait plein = noyau obligatoire ou flux continu. Trait pointillé = module optionnel, activable plus tard sous contrat. Cliquez sur une bulle pour voir les fichiers et son rôle.

Légende simple

Noyau obligatoire : ce qui doit toujours rester clair.
Optionnel : utile, mais seulement si le besoin le justifie.
Pantheon gouverne : règles, preuves, statuts.
OpenWebUI expose : écran, décisions, affichage.
Hermes exécute : profils, skills, tools, candidats.
