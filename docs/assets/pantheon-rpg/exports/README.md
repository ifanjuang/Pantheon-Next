# Pantheon RPG Exports

Status: validated visual exports workspace — not governance doctrine.

This directory stores final or approved visual exports for the Pantheon RPG visual system.

Images should be added here only after review.

## Rules

- Store validated assets only.
- Keep intermediate or rejected images in `../iterations/`.
- Add a short provenance note for each final export.
- Do not add generated images that include private project data, client data, real addresses or confidential material.
- Do not use exported images to claim that a feature is implemented.
