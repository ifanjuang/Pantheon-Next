# Pantheon RPG Iterations

Status: image iteration workspace — not governance doctrine.

This directory stores non-final generated image candidates, review notes and rejected or superseded visual attempts.

Use this directory for work-in-progress outputs only.

Validated final assets should go to `../exports/`.

## Rules

- Keep only iterations that are useful for review or comparison.
- Do not treat an iteration as a validated asset.
- Add a short note when an iteration is kept because of a specific quality or problem.
- Do not add private project data, client names, real addresses or confidential documents.
