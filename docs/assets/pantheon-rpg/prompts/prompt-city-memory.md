# Prompt — City Memory Board v01

Status: accepted visual direction — image export pending binary drop.

This prompt defines the accepted direction for Pantheon RPG planche 2: the governed memory city.

It is a design artifact, not governance doctrine.

## Purpose

Generate a standalone board for the Pantheon RPG visual system focused on the `Cité Mémoire Gouvernée` / `Governed Memory City`.

This board explains project-scoped memory, system memory, knowledge fields, templates, archives, maritime source intake, transmission, skill workshops, domain selection and deliverable fabrication through a single isometric RPG city map.

## Accepted visual direction

The board must preserve:

- a vertical poster format;
- crisp isometric pixel art;
- high-contrast retro strategy-RPG look;
- Greek-antique architectural vocabulary;
- a coastal citadel composition;
- a dark left-side legend panel with numbered and lettered callouts;
- floating professional-domain islands in the upper-right clouds;
- maritime docks on the left;
- rural knowledge/template zones on the right;
- a desert route at the lower-right;
- clear numbered/lettered associations between legend and map.

## Main prompt

```text
Create a standalone vertical isometric pixel-art strategy-RPG board titled "2 Governed Memory City".

The image must show a Greek-antique coastal citadel representing Pantheon Next governed memory. The style must be crisp, high-definition, detailed, visibly pixel-art, and strongly game-like, closer to a polished RPG strategy map than to a corporate diagram.

Use Greek antiquity as the architectural language: cut limestone, terracotta tiled roofs, columns, pediments, porticoes, stoas, civic houses, courtyard houses, stepped streets, small plazas, temples used sparingly, and classical masonry. Avoid medieval castle feeling and avoid generic fantasy Gothic architecture.

The city is a unified citadel beside the sea. The main sea and harbor are on the left. The citadel is compact but not perfectly square. It has terraces, walls, streets, stairs and urban fabric. The central Pantheon is on a raised terrace and has a golden roof. It represents system memory and is marked as 1.

Inside the citadel, show three project neighborhoods:

A = District A / Case A
B = District B / Project B
C = District C / File C

These districts must not be made only of temples. They must read mainly as inhabited Greek-antique neighborhoods with houses, townhouses, courtyard houses, small civic buildings, patios, terraces, and a few modest public buildings. Each district should have a different visual accent while remaining coherent with the same city.

On the left coastal side, show a maritime intake zone with quays, docks, boats, piers, crates, manuscripts, documents, dock workers and source-handling activity. This is marker 8: Quays & Docks / Internet Sources.

Near the lower central coastal zone, show an archive building with marker 6. In the legend, this must read: Archives / archived projects.

On the right and lower-right, show support landscapes:

- marker 5: Pastures / knowledge, represented by sheep in enclosed pastures;
- marker 7: Fields / templates, represented by ordered cultivated fields;
- a desert edge at the lower-right with a route leading outward toward the world of possibilities.

The aqueduct / viaduct must be fully isometric and angular. It must have no rounded curves. It must be built from straight isometric segments with right-angle turns. Each angle must have a small tower or turret. It must not form a rectangular grid over the fields. Keep one elegant routed aqueduct with water visible on top. The viaduct should follow the wall logic between District B and District C, align near the top-right corner of the pasture marked 5, and leave a visible passage between the end of the viaduct and nearby buildings.

Add a pigeonnier near the Pantheon, marked 10. It must be a round rotunda-like pigeon tower with many small holes/openings on the facade. It represents transmission.

Add small skill-forging workshops near the citadel, marked 11. They represent Ateliers / forge skills.

Add floating professional-domain islands in the upper-right sky, with pixel-art clouds. The clouds should be light, slightly semi-transparent and pixel-art. The domain islands represent:

- Law;
- Architecture;
- Medicine;
- Engineering;
- Information.

Mark this area as 12: Domain Selection / choose métier.

At the lower part of the map, show a distinct workshop or output compound marked 13. It represents deliverable fabrication: Deliverables Factory / exports & renders.

Add a clear route in the lower-right desert. The route should visibly start from the road separating marker 13 and marker 6, then move through the desert toward the world of possibilities.

Use a dark blue and gold left-side legend panel in English. The legend must remain compact, readable and associated with visible map markers.

Legend text:

2 Governed Memory City

1 Pantheon — system memory
A District A — Case A
B District B — Project B
C District C — File C
5 Pastures — knowledge
6 Archives — archived projects
7 Fields — templates
8 Quays & Docks — internet sources
9 Foundations — manifests
10 Pigeonry — transmission
11 Workshops — forge skills
12 Domain Selection — choose métier
13 Deliverables Factory — exports & renders

Keep the image high-definition, detailed, crisp and visibly pixel art. Preserve the RPG strategy-map feeling. Do not turn the image into a SaaS dashboard or a flat infographic.
```

## Negative prompt

```text
No modern dashboard, no SaaS UI, no flat vector infographic, no cyberpunk, no server room, no medieval Gothic fortress, no random fantasy castle, no rounded aqueduct curves, no viaduct grid over fields, no city made only of temples, no technical stack labels, no LLM labels, no backend diagram, no uncontrolled memory flow, no autonomous agent control room.
```
