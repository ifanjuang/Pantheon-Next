# Negative Prompt — Pantheon RPG Visual System v01

Status: working visual prompt — not governance doctrine.

## Purpose

This file defines the shared negative prompt for Pantheon RPG image generation.

It prevents visual drift toward medieval fantasy, SaaS dashboards, backend diagrams or autonomous runtime imagery.

## Negative prompt

```text
No medieval castle, no crenellations, no fantasy fortress, no gothic citadel, no knights, no medieval banners, no cyberpunk city, no futuristic spaceship, no data center, no server racks, no command center, no surveillance room, no corporate dashboard, no SaaS UI, no product analytics screen, no flat vector infographic, no modern software architecture diagram, no backend topology, no API gateway chart, no queue diagram, no scheduler diagram, no LangChain, no LangGraph, no RAG labels, no LLM labels, no embedding labels, no vector database labels, no provider router, no autonomous agent control room, no robot workers controlling the system, no technical pipeline illustration, no smooth 3D render, no realistic CGI, no blurry pseudo pixel art, no illegible text walls, no excessive labels, no random modern icons, no smartphone UI, no laptop interface, no neon cyber interface, no glassmorphism, no corporate blue UI, no modern office scene, no militarized fantasy army, no gods as authoritarian rulers, no player removed from decision, no source boats entering the city, no knowledge fields inside the memory city, no automatic memory upload, no uncontrolled data stream into the palace, no hidden machine deciding for the user.
```

## Forbidden doctrine drift

The image must not suggest that Pantheon Next:

- executes tasks directly;
- contains an internal runtime;
- schedules autonomous workflows;
- owns a provider router;
- auto-promotes memory;
- bypasses human validation;
- turns OpenWebUI into canonical memory;
- turns Hermes profiles into governance authority.

## Visual correction rule

If an generated image implies autonomous execution or uncontrolled memory ingestion, reject it even if it is visually strong.
