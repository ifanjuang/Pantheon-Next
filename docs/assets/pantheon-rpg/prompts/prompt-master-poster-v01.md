# Prompt — Master Poster v01

Status: working visual prompt — not governance doctrine.

## Purpose

Generate the first complete vertical poster candidate for the Pantheon RPG visual system.

This prompt is intended to test the global composition:

```text
Cieux des Possibles
Monde Extérieur
Cité de la Mémoire
Ateliers Souterrains
```

It should produce a readable master map, not a final explanatory board with all final typography.

## Scope

This prompt covers:

- global RPG world composition;
- player journey;
- source boats;
- verification docks;
- knowledge fields;
- memory city;
- project districts;
- gods as companions;
- portals;
- quests and side quests;
- traps and enemies;
- underground workshops;
- final validation gate.

It does not attempt to render all explanatory text directly inside the image.

Use short labels only and leave parchment banners or cartouches for later typography overlay.

## Main prompt

```text
Create a very tall vertical isometric pixel art poster showing Pantheon Next as a governed decision RPG world.

The image must look like a real playable 16-bit / 32-bit strategic RPG map, not a corporate diagram and not a modern software dashboard. The poster is a vertical cutaway world with four readable strata: the Cieux des Possibles at the top, the Monde Extérieur around the center, the Cité de la Mémoire as the main central city, and the Ateliers Souterrains below the city.

Global narrative: the user is the player. The player chooses a quest, brings source material, explores knowledge, invokes companion gods, uses skills and tools, avoids traps, receives evidence and a deliverable, then validates, corrects, rejects, relaunches, transmits or saves. Only validated content enters durable memory.

At the very top, create a title zone like an RPG title screen carved into a Greek stone fronton. Large readable title area: PANTHEON NEXT. Add empty parchment banner space for subtitle and short motto. The title zone should feel epic but not fantasy-medieval.

Create the Cieux des Possibles above the city: floating islands, oracle temples, observatories, mirrors, celestial pools, astrolabes, constellations, suspended terraces, light bridges and messenger winds. This layer represents possible paths, scenarios, variants and oracle suggestions. Show several small oracle stations as aerial Greek temples or crystal chambers: rapid, deep, visual, sources, writing, confidential, specialized. Add small Greek companion sprites near the oracle islands: Zeus, Apollo, Iris, Chronos, Artemis, Dionysos, Athena. They must appear as advisors, not rulers. Suggestions should descend as soft light beams, not command lines.

Around the city, create the Monde Extérieur as an explorable RPG landscape: sea, ports, islands, roads, forests, mountains, rivers, ruins, marshes, caves, cliffs, mills, bridges, rural libraries, knowledge villages, fields and orchards. Add fog-of-war in some unexplored zones. Make the landscape semantic: forests for unfiltered information, rivers for data flows, mountains for heavy files, ruins for old archives, marshes for unclear assumptions, cliffs for legal or strategic risk, caves for hidden data, mills for synthesis, bridges for links between sources.

On one side, create maritime source routes. Add several antique isometric ships that stop at the harbor and never enter the city: a small rowboat for a web page, a corsair ship for social networks, a fishing boat with nets and crates for open data, a merchant ship for SaaS platforms, a service ship with cranes and connectors for public APIs, a state galley with seal and banner for official institutional sources, and a black ship far away on the edge of the map for dark web. The ships must remain outside the city.

Between the ships and the city, create the Quais de Vérification: antique stone docks with guards, scribes, registers, open crates, inspected scrolls, stamps, seals and controlled gates. Show the player bringing a crate of sources to a scribe. Add small colored seals for source states: gray raw, blue read, cyan linked, green verified, gold validated, violet archived. The visual message must be clear: external information is inspected before it can support work or memory.

Near the docks but outside the city, create the Champs de Knowledge: agricultural patchworks made from documents, orchards of references, corpus farms, synthesis mills, rural libraries, villages of norms, villages of precedents and public data villages. Knowledge fields must remain outside the city. They may feed quests, but they are not the memory city.

At the center, create a monumental Greek antique city called the Cité de la Mémoire. It must be the visual focus. No medieval castle, no crenellations, no fantasy fortress. Use cut limestone, columns, pediments, stoas, agoras, paved streets, stairs, terraces, propylons, libraries, gardens, controlled streams, bridges and terracotta roofs. The city must look antique Greek, civic, ordered and alive.

Inside the city, place a large central Pantheon palace. This represents system memory. Around it, create separated project districts: Projet Alpha, Projet Beta, Projet Gamma, Projet Delta. Each district must be distinct, separated by streams, low walls, gardens, porticoes, controlled gates, stairs, retaining walls and bridges. Districts can communicate by controlled bridges but must not merge. Each district contains a central square, houses, archives, small temples, scribes, guards, messengers, cartographers and inhabitants.

Make the memory hierarchy visually clear: city equals governed memory, central palace equals system memory, project district equals project memory, square equals work session, house equals discussion or local memory, bridge equals controlled exchange.

Add a few very short dialogue bubbles in project districts: source missing, decision validated, risk to verify, deliverable ready, previous version, official proof, Alpha memory. Keep text minimal and readable.

Near the central palace, create the Conseil des Dieux as an open Greek agora or circular temple. Show companion gods as detailed pixel art sprites: Zeus arbitrate, Hera govern, Athena structure, Apollo clarify, Artemis detect, Ares confront, Hephaistos craft, Hermes transmit, Iris connect, Argos retrieve, Themis verify, Dionysos explore, Demeter cultivate, Mnemosyne memorize, Chronos version, Hestia stabilize. The gods are companions invoked by the player, not autonomous rulers. The player stands at the center of the council.

Show the player as an active RPG hero in multiple moments of the map: choosing a quest, bringing sources to the docks, invoking companions, talking to a project district, reviewing evidence, validating a deliverable, saving to the correct district. The same character can appear several times as a narrative sequence. Add a subtle RPG HUD with level, XP, mana or tokens, reputation, clarity, sources, confidence, risk, validation and memory. The HUD must be discreet, pixel art, not a dashboard.

Add a Domaines frieze or ring of small thematic areas: health as medical sanctuary with herbs and healing pool, architecture as temple and construction site with plans and model, law as agora tribunal with steles and balance, engineering as bridge aqueduct and machine, finance as market vault and coins, research as observatory library and scholarly island, public sector as administrative forum and registers, education as academy and books, consulting as caravan map and compass. Only architecture should look like a construction site.

Add Portails around the city edge. Channels are not boats. Show WhatsApp and Telegram as couriers, falcons and pigeons; Gmail and email as official pigeon tower and mail office; Google Docs and Notion as collaborative scriptoria; Google Sheets as abacus counter and register; Google Drive as document vault; Trello as guild quest board; Calendar as sundial and city bell; Forms as chancery counter; APIs and webhooks as aqueducts and mechanical relays. Show that the player can enter and receive outputs through familiar channels, without making a technical integration diagram.

Add a quest board near the agora, like an antique guild board with scrolls. Main quests: investigation, compliance, comparison, production, strategy, memory, creation, audit. Add smaller side quest scrolls: answer emails, prepare meeting, organize folder, create template, evolve skill, ask project district, ask gods, monitor source, clean temporary memory, prepare activity report. Use short readable labels or mostly pictograms.

In the outer world, add playful but meaningful RPG traps and enemies: context fog, sirens of easy sources near the sea, duplicate goblins carrying repeated documents, proof mimics disguised as treasure chests, assumption marsh, old-version ghosts in ruins, contradiction troll under a bridge, social media pirates around the corsair ship, overload dragon on a mountain of documents, administrative labyrinth, unsealed gate, broken bridge between a source and a conclusion.

Below the city, create the Ateliers Souterrains as an antique underground cutaway. It must look like craft workshops, not a server room. Show galleries, mines, data crystals, forges, anvils, workshops, antique gears, tool depots, armory, scribe presses, rendering chambers, cartography rooms, diagram labs, image workshops and delivery chests.

Inside the underground layer, create the Forge des Savoir-Faire. Show a skill lifecycle as small forge stations: discovered, trial, improved, to validate, reusable. Skills gain XP through use and become reusable only after validation.

Create an Armurerie des Outils as a rack of RPG tools: OCR as runic magnifying glass, PDF parser as scroll knife, D3.js as cartographer compass, GitHub analyzer as version anvil, table extractor as graduated ruler, web scraper as fishing net, SQL query as cellar key, image analyzer as Argos lens, audio transcriber as Iris shell, video analyzer as Chronos lantern, report builder as scribe press, diagram builder as astrolabe, export builder as delivery chest, template engine as matrix scroll, data cleaner as sieve, calendar sync as sundial, Trello sync as quest board, Notion sync as codex, Google Docs sync as shared quill, Google Sheets sync as abacus, Drive sync as document vault.

Show the craft of a final deliverable: source crates plus orientation map plus invoked companion plus tool plus forge plus proof plus sealed deliverable plus delivery chest. The deliverable may appear as a report, synthesis, table, letter, presentation, diagram, action plan, evidence dossier, archive, export, dashboard or decision note.

At the lower center, create the final human validation scene. The player stands before a validation gate with clear action options: validate, correct, variant, reject, relaunch, transmit, save. A sealed deliverable moves only toward the correct project district, not into the whole city. The visual message must be obvious: only validated content becomes durable memory.

At the bottom, create a final banner with large pixel typography space for: EXPLORER. COLLECTER. DÉJOUER. PROUVER. DÉCIDER. ARCHIVER. Add small by IFJA.

Art direction: very tall vertical poster, isometric pixel art, strategic RPG, 16-bit / 32-bit, richly detailed but readable, Greek antique civic world, limestone, ocre, terracotta roof tiles, olive green, dark blue, discreet gold, copper, earth brown, deep red, parchment, soft cyan, subtle violet. Crisp pixel tiles, detailed sprites, atmospheric lighting, clear hierarchy. The image should be visually dense but compositionally controlled, like a playable world map with strong narrative flow.

Use minimal text inside the image. Prefer short labels and blank parchment cartouches for later typography overlay. Prioritize visual storytelling, hierarchy, player agency and doctrine-safe metaphor.
```

## Known risks

### Overload

The prompt contains many visual elements.

If the result is unreadable, the next prompt should split the master poster into four boards:

```text
01-world-overview
02-city-memory
03-source-world-and-traps
04-underground-workshops
```

### Text failure

Image models may fail at small typography.

Use short labels only.

Final typography should be overlaid later in a design tool.

### Runtime confusion

If workshops, gods or oracles look like autonomous controllers, reject the image.

The player must remain the decision-maker.

## Review checklist

Before accepting a generated candidate, verify:

- does it read as RPG world before diagram?
- is the city clearly Greek antique, not medieval?
- is the player visible and active?
- do source boats stop outside the city?
- are verification docks visible?
- are knowledge fields outside the city?
- does the city show separated project districts?
- do gods assist without ruling?
- does the underground look like craft, not backend?
- is validation human and explicit?
- does the deliverable go only to the correct project district?
- is the image readable at three seconds, ten seconds and one minute?
