# AI Literacy Assets

Status: support documentaire, non canonique, non executable.

Ce dossier rassemble les notes pedagogiques destinees aux supports Ulysse / Hercule sur l'usage de l'IA.

Il ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable, aucune politique d'approbation et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## Documents

- `ulysse_ai_traps.md` : matrice principale des dix pieges d'Ulysse.
- `hercule_ai_discipline.md` : matrice principale des douze disciplines d'Hercule.
- `ulysse_scene_cards.md` : fiches detaillees lieu par lieu, avec recit, themes profonds, transposition IA, garde-fou, formule affiche et cartel.

## Statut editorial

Ces documents servent a produire :

- affiches pedagogiques ;
- diptyques Ulysse / Hercule ;
- cartels explicatifs ;
- supports HTML cliquables ;
- livrets ou notes de mediation.

Ils doivent rester distingues de la gouvernance canonique Pantheon.

Une metaphore aide a voir un phenomene.

Elle ne remplace ni l'enquete, ni la source, ni la preuve, ni le jugement professionnel.

## Methode de travail

Pour chaque lieu d'Ulysse ou epreuve d'Hercule, la fiche doit suivre ce parcours :

```text
recit mythologique
-> themes philosophiques, psychologiques, sociologiques et epistemologiques
-> transposition IA
-> piege ou force
-> exemple concret
-> garde-fou
-> formule affiche
-> cartel explicatif
```

Le but n'est pas d'illustrer l'IA par la mythologie de facon decorative.

Le but est de faire apparaitre les tensions reelles de l'usage : attention, desir, jugement, preuve, responsabilite, memoire, transmission et decision.
