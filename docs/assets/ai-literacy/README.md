# AI Literacy Assets

Status: support documentaire, non canonique, non executable.

Ce dossier rassemble les notes pedagogiques destinees aux supports Ulysse / Hercule sur l'usage de l'IA.

Il ne definit aucun runtime, aucun agent, aucun outil, aucun workflow executable, aucune politique d'approbation et aucune memoire canonique.

Doctrine Pantheon preservee :

```text
OpenWebUI expose.
Hermes Agent execute.
Pantheon Next gouverne.
```

## Point d'entree recommande

Pour la partie Ulysse, le point d'entree editorial principal est :

- `ulysse_reconciled_longform.md` : version longue reconciliee du corpus Ulysse, integrant la preface theorique, l'introduction, les dix escales stabilisees, la conclusion et la table finale de mediation.

Ce fichier doit etre utilise en priorite pour :

- article long ;
- livret pedagogique ;
- cartels explicatifs ;
- support de mediation ;
- base de reconciliation avant poster ou version HTML.

Les autres fichiers Ulysse restent conserves comme sources de recherche, matrices courtes ou fiches detaillees.

Ils ne sont pas supprimes, car ils contiennent des formulations, variantes et traces editoriales utiles.

## Regle de reconciliation

Ne pas supprimer les fichiers de recherche tant que leur contenu n'a pas ete explicitement absorbe, verifie ou archive.

La reconciliation doit suivre cet ordre :

```text
1. Stabiliser la version longue reconciliee.
2. Identifier les formulations utiles restantes dans les fichiers sources.
3. Integrer ou ecarter explicitement ces formulations.
4. Marquer les anciens fichiers comme sources historiques ou les deplacer dans une archive dediee.
5. Ne jamais presenter une note de recherche comme une doctrine canonique Pantheon.
```

## Statut editorial

Ces documents servent a produire :

- affiches pedagogiques ;
- diptyques Ulysse / Hercule ;
- cartels explicatifs ;
- supports HTML cliquables ;
- livrets ou notes de mediation.

Ils doivent rester distingues de la gouvernance canonique Pantheon.

Une metaphore aide a voir un phenomene.

Elle ne remplace ni l'enquete, ni la source, ni la preuve, ni le jugement professionnel.

## Methode de travail

Pour chaque lieu d'Ulysse ou epreuve d'Hercule, la fiche doit suivre ce parcours :

```text
recit mythologique
-> themes philosophiques, psychologiques, sociologiques et epistemologiques
-> transposition IA
-> piege ou force
-> exemple concret
-> garde-fou
-> formule affiche
-> cartel explicatif
```

Le but n'est pas d'illustrer l'IA par la mythologie de facon decorative.

Le but est de faire apparaitre les tensions reelles de l'usage : attention, desir, jugement, preuve, responsabilite, memoire, transmission et decision.
