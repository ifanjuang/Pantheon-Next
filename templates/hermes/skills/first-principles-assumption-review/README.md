# first-principles-assumption-review

Status: template only — documented non-implemented.

This directory contains a Hermes-compatible skill template adapted from the external `reshadat/first-principles-destructor` prompt pattern.

It is not installed in Hermes.
It is not task-authorized.
It is not a Pantheon doctrine source.
It does not create approval, proof, canonical memory or external action.

Placement:

```text
Layer: execution runtime
Runtime target: Hermes candidate skill
Pantheon role: governs admission, scope, evidence, approval and memory boundaries only
Output: Assumption Review Candidate + Evidence Pack Candidate
```

Useful use cases:

- testing whether a governance proposal is carrying hidden runtime assumptions;
- reviewing whether a workflow has become too tool-specific;
- challenging data-platform or graph-platform scope creep;
- distinguishing professional method from software habit;
- surfacing proof gaps before an architecture-domain output becomes client-facing.

Forbidden use:

- deciding doctrine by itself;
- replacing Zeus arbitration;
- validating a professional conclusion;
- promoting memory;
- editing repository files;
- authorizing a tool, crawl, external send, merge or publication.

The template should be copied into a real Hermes skill location only after skill admission, manifest/passport review, Task Contract authorization and sandbox verification.
