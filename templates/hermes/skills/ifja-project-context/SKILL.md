# IFJA project context

Use one document-neutral route for project material: Hindsight locates and
reuses known content; the vault resolves the exact source; an admitted
inspection method reads only what the question needs. The source format does
not decide the method or the authority of the result.

## Conversation projection

For non-trivial IFJA work, when `pantheon-activity-projection` is available,
load and apply it before substantial execution. It does not prescribe the runtime tool sequence.
If unavailable, report a presentation capability gap
without inventing an equivalent governance layer.

```text
projection plan != runtime dispatch plan
visible milestone != MCP-prescribed tool sequence
```

## Core route

1. For a named project, dossier or document, call the configured project
   Hindsight router first. It is a continuity and location lead, not source
   authority.
2. If the recalled material answers an orientation question with its source and
   limitations intact, answer as `orientation mémoire — non confirmée`.
3. For an exact fact, calculation, recommendation, clause, current status or
   document-content claim, resolve and inspect the exact source through the
   admitted vault route.
4. Use an admitted representation only when the source or existing Hindsight
   content is insufficient for the question. Prefer the least costly suitable
   method; do not convert, OCR, inspect images or transcribe media by default.
5. For technical, legal, regulatory, contractual or professional-rule testing,
   consult the relevant DOCUMENTAIRES or authoritative source separately from
   the project source.

Read [references/professional-source-routing.md](references/professional-source-routing.md)
before a material professional review. Read
[references/project-resolution.md](references/project-resolution.md) for an
ambiguous project identity, and
[references/document-inspection.md](references/document-inspection.md) when a
source or derived representation must support a claim.

## Boundaries

Do not hard-code workspace paths, Hindsight bank IDs or providers. Do not turn
a memory lead, filename, search hit, representation or parser success into a
source claim. Use `source-research` only when the local sources cannot answer a
material current or external question. Route consequential decisions through
the selected Pantheon binding.

```text
Hindsight recall != source authority
representation != source replaced
retrieved != truth
project source != external rule
memory answer != Evidence
```
