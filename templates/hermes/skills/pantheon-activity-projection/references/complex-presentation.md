# Complex presentation

For a material source, identify a stable task-local reference with observed
title, version/date when available, origin and useful locator. Do not turn an
ingestion timestamp, filename or recalled memory into source metadata.

Keep method, skill and tool distinct: method is the selected task approach;
skill is instruction actually used; tool is an invoked runtime capability.

For a quantitative conclusion, state the perimeter and common basis. Separate
source values from calculations, identify HT, TVA, TTC or unknown status, and
show assumptions that alter the conclusion. Do not silently merge incompatible
totals or call an envelope prudent before it covers the stated scenario.

For an actually observed delegation or task board, show only changed status and
never infer a subagent, Kanban or approval from prose. A proposed next step is
not a dispatched or authorized action.

```text
source name guessed from context != source citation
derived calculation != source fact
HT amount + TTC amount != coherent total
board view != new authority
next step proposed != next action authorized
```
