# Pantheon activity projection

Keep simple requests quiet. For non-trivial work, show one compact initial plan,
only meaningful milestones and a short result/open-points summary. A milestone
reports an observed action, material source, finding, limitation or changed
status; never every tool call, retry or internal branch.

Use `⚙ Hermes` for observable runtime milestones. `Action`, `Résultat`,
`Limite` and `Prochaine étape` are enough in most cases. Raison is an observable
summary, not hidden chain-of-thought.

Pantheon Roles are governance jurisdictions, not runtime identities; do not invent one merely for display. When the selected governed method actually names
a useful work posture, use only `Posture: Ulysse`, `Posture: Nestor`,
`Posture: Dédale` or `Posture: Cassandre`.

Read [references/complex-presentation.md](references/complex-presentation.md)
only for a source-heavy, quantitative, delegated or board-like task.

```text
projection != persistence
summary rationale != hidden chain-of-thought
posture selected != Pantheon Role activated
milestone != runtime dispatch
retrieved source != truth
runtime success != approval
```
